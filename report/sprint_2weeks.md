## 二、到货前 D1~D2（不需要 AD8232）

### D1 上午（3h）· XADC 内部通道自测 ★核心
- 在 BD 中实例化 XADC 原语（或 XADC Wizard），DRP 接到 AXI-Lite 寄存器
- Python 读四个通道：温度(0x00)、VCCINT(0x01)、VCCAUX(0x02)、V_P(0x10)
- **判据**：温度 30~60℃；VCCINT = 1.00V ±5%；VCCAUX = 1.80V ±5%；V_P 与万用表实测 J5 脚1 对地电压一致（±5%）
- 意义：DRP 通路 + 码值→电压的校准公式全部验证完，到货后只换信号源
- 负责人：A（板级/硬件）

### D1 下午（3h）· 数据流骨架
- 把 DDS 从"寄存器轮询"改成"流式"（valid/ready 握手），接 16 抽头 FIR 低通原型
- 仿真：DDS 波形输入 → FIR 输出，与 Python 离线滤波结果比对
- **判据**：逐点误差 ≤ ±1 LSB；综合后 LUT 增量 ≤ 200
- 负责人：B（RTL）

### D1 晚上（1h）· 归档
- L-15 案例写进 `skill/pitfalls.md`（工具链陷阱类）
- 更新 `progress.md`

### D2 上午（3h）· Pan-Tompkins Python 原型 ★核心
- 用现有 `ecg_wave_72bpm.csv` 跑完整离线算法：带通(5~15Hz) → 微分 → 平方 → 移动窗积分(150ms) → 自适应阈值 → R 峰
- **判据**：检出 R 峰间隔 = 206/207 采样点（对应 72 BPM），无漏检/误检
- 产出 `golden_rpeaks.csv`（RTL 检测器的验收标准）
- 负责人：C（算法/Python）

### D2 下午（2h）· XADC 采集测试台
- 用 Vivado XADC 仿真模型写 TB：DRP 读时序、通道切换、连续 100 次采样
- **判据**：模型注入电压与读回码值误差 ≤ 1 LSB
- 负责人：B

### D2 晚上（1h）· 到货预演
- 接线图核对（J5 脚序/分压电阻阻值/杜邦线）→ 拍照存档
- 新版 `ecg_monitor_xadc.py` 草稿（把 MMIO 读数改成 XADC 通道读数）
- 验收清单打印

## 三、D3 及之后（到货后）

### D3 · AD8232 上板（半天出波形，半天调电极）
- 接线：3.3V/GND/SDN→3.3V/OUTPUT→分压→J5 脚1；J5 脚2↔脚3 短接
- **判据**：静态基线 ≈ 0.375V±0.1V（分压后）；贴电极后能看到 R 峰
- 贴电极位置：红=右胸锁骨下、黄=左胸锁骨下、绿=右下腹（参考）
- 风险：电极噪声大 → 用酒精棉擦皮肤、换新电极片；LO+ 接 GPIO 做脱落检测

### D4~D5 · 前端滤波链（RTL）
- 50Hz 陷波（二阶）+ 0.5Hz 高通（去基线）+ 5~15Hz 带通（检测用）
- 三组实验：位宽 12/16/24、窗口 50/100/150ms、是否开通道并行
- **判据**：M3 判据 + 资源/延迟对比表

### D6~D8 · Pan-Tompkins RTL 化
- 按 D2 的 Python 黄金参考逐段对照，先过仿真再上板
- **判据**：M4（重合率 ≥95%）

### D9~D10 · AXI-Stream + DMA
- 从 MMIO 轮询改成 DMA 直传，保留 MMIO 通道做兼容
- **判据**：M5（≥8 倍提速），并把对比数字写进报告

### D11~D12 · HRV + 心律失常 + 报警
- SDNN / RMSSD / pNN50；规则：心动过速/过缓、RR 间期不齐
- 报警：LED + （可选）蜂鸣器；Python 端弹窗

### D13~D14 · 交付整合
- 技能包（pitfalls/prompts/验证脚本）、README（复现步骤）、提交包结构
- **判据**：M7（他人复现成功）

## 五、风险与预案

| 风险 | 概率 | 预案 |
|---|---|---|
| XADC 配置失败/噪声大 | 低 | 备用 SPI ADC（已列采购）；仍失败则回到 DDS 自测数据 + 说明限制 |
| 电极接触噪声大 | 中 | 用酒精擦皮肤、换电极片、加屏蔽线；LO 报警先做 |
| RTL 检测器与 Python 不一致 | 中 | 先用仿真逐级对齐（每级中间结果导出 CSV），不要一步到位 |
| 时间不够 | 中 | S5/S6 可降级：DMA 只做"能跑"、HRV 只做 SDNN；保 M1~M4 的完整链路 |
