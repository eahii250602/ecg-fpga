## 一、已确认结论

### 1.1 Arduino 模拟脚 → FPGA 模拟输入（一一对应）

```
   Arduino 座 A0..A5  ──网名──▶  AR_A0..AR_A5
                                      │ 经板上电阻/电容网络
                                      ▼
                          AR_AN0_P/N   AR_AN1_P/N   AR_AN2_P/N
                          AR_AN3_P/N   AR_AN4_P/N   AR_AN5_P/N
                          （6 对差分命名，单端使用时取 P 端）
```

证据：`pdf_text_out/stream_004.txt`
- 第 247–269 行：`AR_AN0_P` … `AR_AN5_N`（y≈41.9，x=339.7~526.1）
- 第 271–282 行：`AR_A0` … `AR_A5`（y≈152.8，x=259.0~309.4）

**结论：6 个模拟脚与 6 对模拟输入命名严格对齐（A0→AN0 … A5→AN5）。**

### 1.2 ★ 板上已自带分压 + 滤波网络（不需要自己焊分压）

| 元件 | 值 | 图纸坐标 |
|---|---|---|
| R72 / R74 / R78 / R90 / R96 … | 140Ω 1% | (336.7,131.2) 等 |
| R73 / R75 / R85 / R95 … | 845Ω 1% | (361.9,131.2) 等 |
| C3–C7 | 1000pF 50V | (346.7,111.0) 等 |
| R106 / R107 / R109 | 200Ω 1% | (220.7,75.7) 等 |

证据：`pdf_text_out/stream_004.txt` 第 371、397、419、461、468、532、535 行

**含义**：AD8232 的 0~3.3V 输出可以直接接 A 脚（无需外置分压）；
**但分压比必须先实测**——140Ω 与 845Ω 谁是串联、谁是并联决定衰减是 0.14 还是 0.86（差 6 倍）。

### 1.3 供电脚

`VCC3V3`、`VCC5V0` 在 Arduino 座上（`stream_004.txt` 第 168、169、171、174、176、177 行）。
AD8232 从 **VCC3V3** 取电（AD8232 绝对最大电源 3.5V，禁止接 5V）。

## 三、标定实验方案（等 AD8232 到货后执行）

目标：只解决**一个**未知数——我们要用的那个模拟脚（A0）对应哪个 VAUX 通道，以及板上分压比。
（按"最小必要实验"原则，只标定 A0，不逐个标定 6 个脚。）

```
1. AD8232 只上电不贴电极 → 万用表量 OUTPUT 脚直流电压，记 V_out
2. 用电阻搭 0.3V 小分压（如 10k + 1k 从 VCC3V3），接 A0
   —— 0.3V 在任何分压比下都不超 XADC 量程，安全
3. XADC 配置为序列器扫全部辅助通道，读出 16 个通道值
4. 读数明显不为 0 的那个通道 = A0 的通道号
5. 板上分压比 = 读数 / 0.3V
6. 撤掉分压，接 AD8232 输出 → 用 V_out 与读数复核分压比
```
