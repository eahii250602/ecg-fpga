## 一、协作的形式与边界

模型能够在给定问题内给出高质量的解，但它不会替你决定**什么值得做、什么算做完、凭什么说做对了**。

本项目的协作即建立在这一分界上：

| 由 AI 承担 | 由本人承担 |
|---|---|
| 方案枚举、量化依据、代价分析 | **最终取舍** |
| RTL、定点模型、testbench、板端脚本的实现 | 实现正确性的**判定标准** |
| 时序违例归因、换算链推导 | 结论的**采纳** |
| 决策记录与文档的撰写 | 记录的**体例与条目结构** |
| —— | **全部物理操作**（焊接、接线、上电、量测、贴附电极） |

这一分界不是静态的。项目前两周，它曾向模型一侧倾斜——核对、验收、测法均由模型自行判断，
由此产生两次事故（§五）。此后分界被规则固定下来（§六）。

## 二、目标的设定

模型对"做一个心电采集系统"的默认理解，是交付一条能出波形、能测心率的链路。
按这个标准，项目在第三周即可"完成"。

第二个阶段所做的，是将这一目标改写为可检验的形式。改写分两步。

**第一步，以四条硬性约束排除一整类提案**：必须是架构层面的升级而非增加小功能；
须有真实应用价值；每项优化须由已发现的具体不足驱动；技术栈须完整覆盖。
四条约束将讨论的上限从"还能加什么"压到"哪个不足尚未解决"。

**第二步，对照评分表审计初版，得到七条带证据的不足**：自闭环（波形由 DDS 产生再由自身检测）、
计算负载近似为零、波形数据走控制通道（1024 点 = 2048 次 MMIO）、检测器过于简化、
`rr_count` 实测与理论矛盾、软件栈单薄、交付物空白。每条标注对应的评分损失。

由此形成六层目标架构：采集、处理、传输、系统、智能、自检。
**此后每一项工作都须对应其中某一条不足，无法对应者不予立项。**

这一改写的效果是明确的：它把"升级"从一个开放问题变成了有限问题。

改写同时确定了取舍原则：**技术栈的完整性不作为目标**。指南列举的 HLS、AXI-Stream、DMA
三项在前两阶段未落地，原因是排期在后，而非评估后舍弃。其中 DMA 的判断经历过一次修正——
第一次以数据率 500 B/s 为由否决；第二次补入"采样时刻的控制权"这一维度后改为采纳。
两次判断均有量化依据，**修改结论的原因是依据不完整，而非立场变化**。

## 三、验收标准的先行设定

模型的默认验收标准是"结果合理"。本项目在实现之前先行设定四条标准：

| 标准 | 被拒绝的替代方案 | 理由 |
|---|---|---|
| 结构变更后与定点模型**逐位相同** | "误差在可接受范围" | 无法区分结构优化与算法退化 |
| 算法正确性以**注入已知量**验证 | "波形形态正确" | 形态相似不能排除系统性偏差 |
| 采样抖动 **< 16 ns** | "差不多够用" | 抖动直接决定滤波器频率响应的有效性 |
| 抑制比以**单频激励**测量 | 以"心电 + 干扰"混合信号测量 | 混合信号的频谱泄漏会掩盖真实抑制比 |

标准先于实现，其后果是可见的：滤波链第一次重建因时序不收敛被退回；
第二次重建之前须先通过逐位比对；抑制比得出异常结果时先推翻测法而非修改设计。
**这些返工不是效率损失，而是标准生效的证据。**

与验收标准并列的，是记录本身的格式约束：每条决策须写清**备选方案 → 选择 → 量化依据 → 代价**，
至第四阶段累计 23 条（`report/design_decisions.md`，428 行）。

该格式曾检出一处数字不自洽：某条记录称读取 1024 点"比采样速度快 3000 倍"，
而按其自身给出的绝对值（4096 ms ÷ 0.3 ms）反算应为 13600 倍；
且该 0.3 ms 只计 AXI 协议耗时，遗漏了 Python 每次 `mmio` 调用的 0.5~2 µs，
2048 次调用实际为 1~4 ms。

勘误给出的不是替换数字，而是一条校验规则：**给出的倍数必须能由给出的绝对值用同一公式推出。**
此后所有对比数据均须满足该闭合条件，否则视为未完成论证。

## 四、四个协作过程

以下四例说明协作的实际形态：模型提供方案与论证，本人作出判断，结论由数据确定。

### 4.1 滤波器架构：由"不可实现"导出功能重分配

原设计含 0.5 Hz 数字高通，用于抑制基线漂移。模型的分析指出其极点半径 0.9911，
`A(1) = 1.565e−4`，输出量化误差经反馈环放大 6389 倍；并实测四种实现，
误差分别为 3198 / 729 / 17 / 140 LSB，判据为 2 LSB，**无一达标**。

若只到这里，结论是"该级难以实现"。本人的判断是：既然结构在给定字长下不可实现，
就应当改变功能归属，而非继续优化实现。于是基线漂移改由模拟前端高通、PT 内部带通、
PS 侧软件去基线三者分担。

**结果**：滤波链由三级降为两级，定点误差 1.67 LSB，为后续时序收敛留出余量。

### 4.2 时序：归因与等价性检查的分离

滤波链首次重建 WNS 为 −6.363 ns，289 个端点违例。模型的归因路径为：
前 8 条最差路径全部源自同一单元 `u_filt/s2_p2`，问题因此归一化到单一模块；
拆分方案为三级流水（乘法 / 加法树 / 移位饱和），并将饱和比较位宽由 36 位降至 22 位。

本人在此之前增加了一道前置条件：**结构改动后必须先重跑逐位对账，通过方可重建。**
理由是拆分流水线与算法退化在数值上表现相似，仅凭"误差小"无法区分。

**结果**：三次重建，功能零回归；最终 WNS +0.741 ns，TNS 0，0 Critical Warning。

### 4.3 检测器异常：从六个假设收敛到唯一原因

板级出现"检测数停滞"，可解释为链路失效、漏检、或阈值失配，三者修改方向互斥。
模型在前四轮分别提出输入序列、判定平顶、链路停止、事件丢弃四种假设，并逐一修改，
均被后续数据否证。

本人的判断是停止修改，先建立观测手段：将 PT 内部滑动和写入波形缓冲的调试通道，
回读得 `max = 395139`、每 206 点一峰，证明前端链路正常；
再以 `0x8000 | r_index` 事件打标，回读 `82/289/495/702`，与黄金参考偏差 ≤1，
证明每一拍均被检出。

至此可能集只剩"时基"一项。第五轮以三个独立量交叉验证（`Clocks` 读数 62.5 MHz；
20 秒检测数对应 44.95 BPM；每拍 206.5 点反推 154.7 Hz），锁定 PS 时钟实际为 62.5 MHz，
Block Design 所配的 100 MHz 从未在运行时生效。

**结果**：`TICK_DIV` 由 400000 改为 250000，全部频率字重算，问题消失。
一个错误前提曾同时派生三个看似无关的现象。

### 4.4 抑制比：先怀疑测法，再怀疑设计

板级实测抑制比 −3.4 dB，与仿真预期相差 12 倍。模型先后提出两种解释并配套修改脚本：
缓冲未刷新（等待时间 2.5 s → 5.0 s）、注入幅度仅为设定值的一半（以纯正弦校核幅度提取函数）。
前者被数据否证（读数基本不变），后者反而证明测量函数本身正确（输入 600 LSB 测得 600.3 LSB）。

本人要求转向核验测法本身。第三轮关闭心电（`FTW = 0`）仅保留纯正弦，
测得抑制比 −68.5 dB。原因由三个测试缺陷叠加构成：心电峰值已达 12 位上限导致饱和削顶、
R 波窄脉冲的频谱泄漏落于 50 Hz 附近、缓冲窗口未覆盖完整周期。

**结果**：滤波器自始至终正常，失效的是测量方案。

## 五、AI 的错误与代价

| 类型 | 案例 | 代价 | 发现方式 |
|---|---|---|---|
| **幻觉** | 核对表标注通过，被核对文件不存在 | 缺陷带至综合 | `Synth 8-3848` 警告 |
| **机制误判** | 未核验 `.gen` 缓存，综合使用落后 18 分钟的副本 | 一次无效构建 | 源文件与缓存时间戳比对 |
| **推理失效** | 冻结事件连续六个假设全部失败 | 约一个工作日 | 以 xsim 复现板级时序后定位 |
| **推理失效** | −3.4 dB 归因于缓冲未刷新 | 一轮脚本修改 | 延长等待后读数不变 |
| **推理失效** | 自相关峰值 0.237 判为存在心搏 | 一轮分析 | 折叠平均后幅度等于噪声本底 |
| **推理失效** | 周期扫描 52.2 码判为有效心电 | 一轮分析 | 波形宽度为 QRS 的 7.6 倍 |
| **事实错误** | 默认 PS 时钟为 BD 所配的 100 MHz | 约三小时排查 | 三个独立量交叉验证 |
| **数字不自洽** | 决策记录称读取"快 3000 倍"，按同一公式应为 13600 倍 | 需补勘误 | 用绝对值反算 |
| **算法缺陷** | EDR 输出恰为真实呼吸率的 2 倍 | 一轮修正 | 注入已知量的判据 |

三类成因：

**幻觉**源于以陈述替代证据。对策不是要求"更仔细"，而是要求格式化的证据（行号、哈希、时间戳）。

**机制误判**源于不验证工具行为。缓存、比特流路径、寄存器复位状态，这些不体现在源码中的事实，
模型默认其符合常识。对策是把核验写入流程。

**推理失效**源于沿错误假设生成自洽论证。这是模型最稳定的行为特征：
给定假设后能给出高质量推导，但不会自发检验假设本身。因此推进方式只能是
由本人以测量数据裁定取舍。全周期被数据推翻的结论共九项。

## 七、经验

**有效的用法**：要求可被证伪的假设，而非结论；要求把参数偏差换算为功能影响；
要求逐位等价而非误差范围；要求格式化的证据。

**无效的用法**：让它"继续优化"——没有判据时它持续增加内容；以单次读数下结论；
以"看起来对"验收。

模型在给定问题内足够强，但它不检验问题本身。
**协作的效率取决于问题与判据的质量，而非提示词的措辞。**
