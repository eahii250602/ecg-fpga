# D3 实验室操作卡（AD8232 → J5 → XADC）

> 日期：2026-10-26 下午 · 目标：**看到第一帧真实心电**
> 前提：板子已刷含 XADC 的比特流（MD5 `35E95711…`），SD 卡里有 `ecg_bd.bit/.hwh`

## 0. 到实验室先清点（每样都要在）

| # | 物品 | 用途 | 备注 |
|---|---|---|---|
| 1 | AD8232 模块 + 3 导联线 + 电极片 | 采集 | 你照片里那包 |
| 2 | PYNQ-Z2 板 + 供电 + 网线/串口线 | 跑设计 | 已刷好 XADC 比特流 |
| 3 | **3.3kΩ 电阻 ×1、1.1kΩ 电阻 ×1**（多带 2 个备用） | 分压 ÷4（3.3V→0.83V） | 缺这个就不能接 |
| 4 | 面包板 | 搭分压 | |
| 5 | 杜邦线：**公头对母头**（或公对公）若干 | J5 是**排母**，要公头插进去；AD8232 排针是公头，要母头 | 没有公头线就插不进 J5 |
| 6 | 万用表 | 量分压电压、XADCVREF | 必需 |
| 7 | 笔记本电脑（Vivado/PuTTY/读卡器） | 拷脚本、看串口 | |
| 8 | 酒精棉片（可选） | 擦皮肤，电极接触好 | 强烈建议 |

## 1. 接线（**先别接 J5！先搭分压并量电压**）

```
        AD8232                     面包板                     PYNQ-Z2
   ┌──────────┐
   │ 3V3  ────┼─────────── 3V3（Arduino 排针的 3V3，绝不能接 5V）
   │ GND  ────┼───────┬──── GND（与分压、J5 脚2/3 共地）
   │ OUTPUT ──┼── 3.3k ── 中点 ── 1.1k ── GND
   │          │              │
   │          │              └── J5 脚1（XADC_V_P）
   │ SDN  ────┼─────── 3V3（拉高=使能；悬空可能不工作）
   │ LO+ / LO-┼── 悬空（导联脱落指示，不用）
   └──────────┘
   J5 脚2（XADC_V_N）── GND
   J5 脚3（XADCGND）  ── GND
   J5 脚4（XADCVREF）── 万用表量一下（记录数值，先不接）
```

**分压计算**：中点 = OUT × 1.1/(3.3+1.1) = OUT ÷ 4。
OUT 静态约 1.65V（3.3V 的一半）→ 中点约 **0.41V**，QRS 时在 0.2~0.6V 间摆；XADC 单端上限 1.0V，**余量足够**。

## 2. 上电前检查（万用表，必须做）

1. 先只给 AD8232 上电（3V3/GND），**OUT 先不接分压**：量 OUT 对地电压，应在 **1.5~1.8V** 左右（说明芯片工作）；
2. 接上分压后再量中点：应在 **0.38~0.45V**；
3. 量 J5 脚 4（XADCVREF）对地：记录数值（预期有 1~3V，以实际为准）；
4. 确认以上都正常，**才把中点接 J5 脚1**。

## 3. 上板

```bash
sudo -s
source /etc/profile.d/pynq_venv.sh
source /etc/profile.d/xrt_setup.sh
cp /boot/ecg_bd.bit /boot/ecg_bd.hwh /boot/ecg_monitor_xadc.py /home/xilinx/
md5sum /home/xilinx/ecg_bd.bit /boot/ecg_bd.bit      # 必须是 35e95711c1ab7b9c29d11ef3453216eb
cd /home/xilinx
python3 ecg_monitor_xadc.py 10                      # 采 10 秒
```

## 4. 贴电极（3 导联，单导联 ECG）

- **RA（红）**：右腕内侧 或 右锁骨下；**LA（黄）**：左腕内侧 或 左锁骨下；
- **RL（绿/黑）**：右小腿 或 右下腹（参考/共模，必须贴，提高共模抑制）；
- 贴之前用酒精棉片擦一下皮肤（去油脂），电极贴紧；
- 电极片用完后放回铝箔袋密封。

## 5. 判据（第一帧真实心电）

- 电压在 **0.1~0.9V** 内、随心跳周期波动（约 1 秒 1 次 = 60BPM，或更快）；
- 波形上能看到**周期性 QRS 尖峰**（P/T 波小，看不明显也算成功）；
- 把 `xadc_ecg.png` / `xadc_ecg.csv`（/boot 里也有）拿回来，我们做下一阶段。

## 6. 常见问题对照表

| 现象 | 最可能原因 | 处理 |
|---|---|---|
| 读数全 0 | 没加载 overlay / J5 没接 / V_N 没接地 | 先跑 `xadc_selftest.py` 确认通道活着，再查接线 |
| 读数恒定 ~0.41V 不动 | AD8232 没供电 / SDN 没拉高 / OUT 没接分压 | 量 OUT 电压、查 SDN |
| 50Hz 噪声很大（密锯齿） | 引线长、离电源近、共地不良 | 缩短引线、远离电源、检查共地 |
| 波形乱跳、基线漂移 | 电极接触不良 / 身体晃动 | 擦酒精重贴、放松别动 |
| 电压 >0.9V 或 <0.05V | 分压错 / 接错脚 | 万用表逐点量，重新算分压 |

## 7. 安全红线

- **AD8232 只接 3.3V，绝不接 5V**（绝对最大 3.5V）；
- 分压后的电压**先量再接 J5**，XADC 单端上限 1.0V；
- 不要带电插拔 J5 排针。
